# Коды ответов и флаги предупреждений (раздел 3.4 Протокола)

## Как читать ответ

```
code        = ANSWER & 0x7F   // код ответа
has_warning = ANSWER & 0x80   // выставлен хотя бы один флаг предупреждения
```

Ответ с предупреждением — успешный ответ. Флаги читаются командой `30h`
(байт «Флаги предупреждения»).

## Универсальные коды (Таблица 4)

| Код | Описание | Комментарий |
|---|---|---|
| `00h` | Успешное выполнение команды | — |
| `01h` | Неизвестная команда, неверный формат посылки или неизвестные параметры | Команда не найдена либо формат/длина/тип параметров не соответствует Протоколу |

## Специальные коды (Таблица 5)

| Код | Описание | Что делать / комментарий |
|---|---|---|
| `02h` | Другое состояние ФН | Команда требует другого этапа или условий выполнения |
| `03h` | Отказ ФН | Запросить детали командой `35h`, перезапустить ФН |
| `04h` | Отказ КС | Запросить детали командой `35h`, перезапустить ФН |
| `05h` | Параметры не соответствуют сроку жизни ФН | Изменить параметры команды |
| `07h` | Некорректная дата и/или время | Проверить дату/время операции |
| `08h` | Нет запрошенных данных | Данных нет в Архиве ФН (часто — штатное завершение чтения) |
| `09h` | Некорректное значение параметров | Формат верный, значение неверно |
| `0Ah` | Некорректная команда (только ФФД-1.1) | Команда не разрешена в этом режиме |
| `0Bh` | Неразрешённые реквизиты (только ФФД-1.1) | В данных ответа — номер некорректного реквизита, Uint16 LE |
| `0Ch` | Дублирование данных | Номер дублируемого реквизита — Uint16 LE в данных ответа |
| `0Dh` | Отсутствуют данные для корректного учёта | Для завершения чеков может быть доп. байт о недостающих суммах |
| `0Eh` | Превышено число позиций в документе | — |
| `10h` | Превышение размеров TLV-данных | — |
| `11h` | Нет транспортного соединения | Установить ТС с ОФД |
| `12h` | Исчерпан ресурс ФН | Требуется закрытие ФН |
| `14h` | Ограничение ресурса ФН | См. флаги предупреждений: время ожидания ОФД > 30 дней или Архив заполнен на 90%; без флагов — исчерпан 30-дневный ресурс |
| `16h` | Продолжительность смены превышена | Смена > 24 ч, требуется закрыть |
| `17h` | Некорректный промежуток времени между ФД | Расхождение более 5 минут с таймером ФН |
| `18h` | Некорректный реквизит, переданный ККТ | — |
| `19h` | Реквизит не соответствует регистрации | Подакцизность / код налогообложения |
| `20h` | Некорректный ответ (код обработки ответа в ФН) | Ответ не может быть принят |
| `23h` | Отрицательный ответ сервиса обновления ключей проверки КМ | — |
| `24h` | Неизвестный ответ сервиса обновления ключей проверки КМ | — |
| `30h` | Требуется повтор обновления ключей проверки КМ | — |
| `32h` | Запрещена работа с маркированными товарами | При активации ФН 1.2 не установлен признак работы с маркировкой |
| `33h` | Неверная последовательность команд группы `Bxh` | — |
| `34h` | Работа с маркировкой временно заблокирована | Переполнена область временного хранения уведомлений |
| `35h` | Переполнена таблица проверки КМ | Не более 128 КМ в чеке |
| `36h` | Превышен период 90 дней с последнего обновления ключей | Выполнить обновление ключей |
| `3Ch` | В TLV-блоке отсутствуют необходимые реквизиты | Может сопровождаться номером реквизита Uint16 LE |
| `3Eh` | В реквизите 2007 КМ, который ранее не проверялся | — |

Конкретные команды дополнительно ограничивают список кодов — смотри описание
команды в `service-commands.md` и разделе 4 Протокола.

## Флаги предупреждений (Таблица 9, байт «Флаги предупреждения» команды `30h`)

| Бит | Маска | Описание |
|---|---|---|
| 0 | `0x01` | Срочная замена ФН (до окончания срока действия 3 дня) |
| 1 | `0x02` | Исчерпание ресурса ФН (до окончания срока действия 30 дней) |
| 2 | `0x04` | Переполнение памяти ФН (Архив ФН заполнен на 99%) |
| 3 | `0x08` | Превышено время ожидания ответа ОФД |
| 4 | `0x10` | Отказ по данным форматно-логического контроля (из Подтверждения ОФД) |
| 5 | `0x20` | Требуется настройка ККТ (из Подтверждения ОФД) |
| 6 | `0x40` | ОФД аннулирован (из Подтверждения ОФД) |
| 7 | `0x80` | В таблице не описано; не интерпретировать без документа |

## Практика отображения

- Показывай код ответа и человекочитаемое описание; для `03h`/`04h`
  предлагай запросить `35h`.
- Не считай предупреждения ошибкой: выведи их отдельным блоком.
- `08h` при постраничном чтении (`46h`, `47h`) — признак конца данных, а не
  сбой.
- При `12h`/`14h`/`16h` сообщай, что требуется закрытие ФН или смены, а не
  «повторите операцию».
