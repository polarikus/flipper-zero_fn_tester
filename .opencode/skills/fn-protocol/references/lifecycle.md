# Этапы применения ФН (раздел 3.6 Протокола)

Этап определяет, какие команды доступны. Переходы только в одну сторону:
вернуться на предыдущий этап невозможно.

| Этап | Код в `30h` | Смысл | Чем завершается |
|---|---|---|---|
| 1 | `1` | Готовность к отчёту о регистрации ККТ или к отчёту об изменении параметров регистрации в связи с заменой ФН | Формированием такого отчёта (активизация ФН) |
| 2 | `3` | Эксплуатация: фискальные документы о расчётах, перерегистрация, отчёт о закрытии ФН | Формированием отчёта о закрытии ФН |
| 3 | `7` | Передача документов в ОФД без формирования документов о расчётах | Подтверждением оператора для отчёта о закрытии ФН (только режим передачи данных) |
| 4 | `15` | Считывание данных из Архива ФН | Через 5 лет после перехода на этап 4 |

ФН в автономном режиме на этапе 3 не применяется: со 2-го этапа переходит
сразу на 4-й.

## Доступность групп команд (Таблица 6)

| Группа | Этап 1 | Этап 2 | Этап 3 | Этап 4 |
|---|---|---|---|---|
| Статусные команды | да | да | да | да |
| Активизация ФН | да | нет | нет | нет |
| Формирование ФД | нет | да | нет | нет |
| Закрытие ФН | нет | да | нет | нет |
| Информационный обмен с ОФД | нет | да | да | нет |
| Получение данных из Архива ФН | да | да | да | да |

## Практические следствия

- `10h` (параметры смены) — только этап 2; иначе `02h`.
- `40h`, `46h` — этапы 2 и 3; `47h` — этапы 2–4; `45h` — этапы 3 и 4.
- `32h` (срок действия) и `3Ah` (формат) доступны на всех этапах.
- `3Bh` (остаток дней) имеет смысл на всех этапах, но дата в запросе не может
  быть раньше даты активизации.
- На этапе 1 регистрационные данные отсутствуют: `43h`/`44h` вернут `02h`.
- На этапе 4 формирование документов и обмен с ОФД недоступны — только чтение
  Архива ФН.

## Связь с версией ФФД

Не путать:

- **этап применения** — `1/3/7/15` (битовая маска в `30h`);
- **код версии ФФД** — `0/1/3/4` (в `3Ah`): `0` — не активизирован, `1` —
  ФФД 1.0/1.05, `3` — ФФД 1.1, `4` — ФФД 1.2.

Один и тот же код `4` в разных полях означает разные вещи: в `30h` это этап 4,
в `3Ah` — ФФД 1.2.

## Что проверять в тестере ФН

1. `30h` → этап, состояние смены, флаги.
2. `3Ah` → текущая и максимальная версия ФФД.
3. `32h` + `3Bh` → срок действия и остаток дней.
4. `3Dh` → ресурс памяти (с учётом опционального третьего байта).
5. Для ФФД 1.1/1.2 дополнительно `10h` и, при необходимости, `36h`/`37h`.
