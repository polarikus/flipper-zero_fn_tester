# Чтение Архива ФН (разделы 4.8, 4.9 и приложение 5.1)

Общее правило постраничного чтения: команду `46h`/`47h` подают до тех пор, пока
ФН не вернёт `08h` — «Нет запрошенных данных». `08h` здесь означает конец
данных, а не ошибку.

## 40h — Найти фискальный документ по номеру

Вход: `Номер фискального документа`, Uint32 LE (4).

Выход:

| Поле | Тип | Длина |
|---|---|---|
| Тип документа (совпадает с типом TLV) | Byte | 1 |
| Получена ли квитанция из ОФД (`1` — да, `0` — нет) | Byte | 1 |
| Данные фискального документа | DataN | N |

Коды: `02h` — ФН не на 2-м/3-м этапе; `08h` — документ не найден; `03h` —
отказ ФН (детали через `35h`).

## 41h — Квитанция ОФД по номеру документа

Вход: номер документа, Uint32 LE. Выход: DataN — квитанция о получении
документа от ОФД.

Коды: `02h`, `08h` (нет документа или квитанции), `03h`.

## 42h — Количество ФД без квитанции

Входных параметров нет. Выход: `Количество неподтверждённых ФД`, Uint16 LE.

## 43h — Итоги открытия ФН

Входных параметров нет. Формат зависит от режима ФФД.

ФФД 1.0/1.05 (Таблица 98):

| Поле | Тип | Длина |
|---|---|---|
| Дата и время | DATE_TIME | 5 |
| ИНН | ASCII | 12 |
| Регистрационный номер ККТ | ASCII | 20 |
| Код налогообложения | Byte | 1 |
| Режим работы | Byte | 1 |
| Номер ФД | Uint32 LE | 4 |
| Фискальный признак | Uint32 LE | 4 |

ФФД 1.1 (Таблица 99) добавляет после «Режим работы» поле «Расширенные признаки
работы ККТ» (Byte) и «ИНН ОФД» (ASCII 12), затем номер ФД и ФПД.

Код `02h` — отчёт об открытии ФН не формировался, регистрационных сведений нет.

## 43h (вариант 2) — Итоги регистрации/перерегистрации

Вход: `Порядковый номер отчёта о регистрации/перерегистрации`, Byte.

Выход для ФФД 1.0: дата/время (5), ИНН (12), рег. номер ККТ (20), код
налогообложения (1), режим работы (1), **код причины перерегистрации** (1),
номер ФД (4), ФПД (4).

Выход для ФФД 1.1/1.2: дата/время (5), ИНН (12), рег. номер ККТ (20), код
налогообложения (1), режим работы (1), расширенные признаки (1), ИНН ОФД (12),
**код причины изменения сведений о ККТ** Uint32 LE (соответствует TLV 1205),
номер ФД (4), ФПД (4).

## 44h — Параметр открытия ФН

Вход: `Тип T`, Uint16 LE (тег TLV). Выход: TLV параметра.

Вариант 2: вход — `Порядковый номер отчёта` (Byte) + `Тип T` (Uint16 LE).
Если второй параметр равен `FFFFh` (65535), команда только подготавливает
постраничное чтение, а сами TLV читаются командой `47h` до кода `08h`.

Данные доступны только после успешного формирования отчёта об открытии ФН.

## 45h — Запрос фискального документа в TLV-формате

Вход: номер ФД, Uint32 LE.

Выход: `Тип фискального документа` (Uint16 LE, тип STLV) и `Длина данных
документа` (Uint16 LE).

Далее `46h` читает по одному TLV верхнего уровня, пока не придёт `08h`.
Коды: `02h` — ФН не на 3-м/4-м этапе; `08h` — документ не найден; `03h`.

## 46h — Чтение TLV фискального документа

Входных параметров нет. Выход: одна структура TLV/STLV верхнего уровня
(`TLV`, длина `L+4`).

Требования: предварительно выполнена `45h`; ФН на 2-м или 3-м этапе.
Коды: `02h`, `08h` (всё прочитано), `03h`.

## 47h — Чтение TLV параметров открытия ФН

Входных параметров нет. Выход: один TLV/STLV верхнего уровня.

Требования: предварительно вызвана `44h` с `FFFFh` во втором параметре.
Коды: `02h` (ФН не на 2-м/3-м/4-м этапе), `08h` (всё прочитано), `03h`.

## 50h — Документ в формате ФФД 1.1/1.2

Вход: номер документа, Uint32 LE.

Выход начинается с `Признак формата` (Byte):

- `0` — формат данных такой же, как у `40h`;
- `1` — данные, подписанные ФПА (только для кассового чека/БСО и чека/БСО
  коррекции).

Для признака `1` далее идут: признак реквизита 1192 (1), тип документа (1),
дата/время (5), номер ФД (4), ФПД (4), сумма операции Uint40 LE (5), тип
операции (1), ФПА (12), суммы по видам оплаты и НДС по Uint40 LE (5) каждая,
значение реквизита 1192 (16, если признак = 1), список STLV «предмет расчёта»
(тег 1059, не более 10), TLV 1055, TLV 1228 либо 1245+1246.

## Форматы документов при выгрузке (приложение 5.1)

| Документ | Поля |
|---|---|
| Отчёт о регистрации, ФФД 1.0 | дата/время, № ФД, ФПД, ИНН, рег. № ККТ, код налогообложения, режим |
| Отчёт о регистрации, ФН-1.1 | то же + расширенные признаки, ИНН ОФД |
| Отчёт об изменении параметров | дата/время, № ФД, ФПД, ИНН, рег. № ККТ, код налогообложения, режим, код причины |
| Отчёт об изменении, ФН-1.1 | то же + расширенные признаки, ИНН ОФД, код причины Uint32 |
| Кассовый чек/БСО | дата/время, № ФД, ФПД, тип операции, сумма операции Uint40 LE |
| Открытие смены | дата/время, № ФД, ФПД, № смены Uint16 LE |
| Закрытие смены | дата/время, № ФД, ФПД, № смены Uint16 LE |
| Закрытие ФН | дата/время, № ФД, ФПД, ИНН, рег. № ККТ |
| Текущее состояние расчётов | дата/время, № ФД, ФПД, кол-во неподтверждённых документов, дата первого неподтверждённого |
| Подтверждение оператора | дата/время, ФПО (18), № ФД |

Форматы `DATE_TIME` и целых — см. `data-types.md`.
