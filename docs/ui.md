# UI: вёрстка и кириллический шрифт

## 1. Вёрстка 128×64

Константы — в `ui/fn_ui.h` (значения фиксированы контрактом
`specs/001-fn-tester-ux/contracts/ui.md` §5):

| Константа | Значение | Назначение |
|---|---|---|
| `FN_UI_MARGIN_X` | 2 | левый/правый отступ |
| `FN_UI_HEADER_H` | 12 | высота инверсной плашки заголовка |
| `FN_UI_CONTENT_Y` | 13 | начало области контента |
| `FN_UI_CONTENT_H` | 50 | высота области контента |
| `FN_UI_LINE_H` | 9 | строка основного шрифта |
| `FN_UI_SMALL_H` | 7 | строка мелкого шрифта |
| `FN_UI_SECTION_GAP` | 3 | отступ между секциями |
| `FN_UI_SCROLLBAR_W` | 3 | ширина скроллбара |
| `FN_UI_TEXT_W` | 120 | доступная ширина текста |

Правила:

- текст рисуется только чёрным по белому (без XOR), инверсия — только фон
  выделенного пункта меню;
- длинная строка переносится по словам, слово шире `max_width` — посимвольно
  (без обрезки);
- подсветка выбранного пункта закрывает и нижние выносы «ф», «ц», «щ»
  (`canvas_draw_box(..., item_h + 2)`), иначе они теряются на белом;
- прокрутка — шаг `FN_UI_LINE_H`, `elements_scrollbar` справа, если контент
  выше `FN_UI_CONTENT_H`.

## 2. Шрифты (`ui/fn_font.c`)

| Параметр | Основной | Мелкий |
|---|---|---|
| Исходник u8g2 | `u8g2_font_haxrcorp4089_t_cyrillic` | `u8g2_font_5x7_t_cyrillic` |
| Автор/лицензия | Copyright sahwar 2009 (free) | public domain |
| Размер данных | 1696 Б | 1934 Б |
| Высота строки | 9 px (`FN_UI_LINE_H`) | 7 px (`FN_UI_SMALL_H`) |
| API | `fn_font_primary()` | `fn_font_small()` |

Итого 3630 байт — в бюджете 6 КБ (контракт §6).

Штатные `FontPrimary`/`FontSecondary` прошивки **не содержат кириллицы**
(проверено разбором `firmware.elf`), поэтому весь русский текст рисуется
только этими шрифтами:

```c
canvas_set_custom_u8g2_font(canvas, fn_font_primary());
canvas_draw_str(canvas, x, baseline, "Информация об ФН");
```

`canvas_draw_str()` в прошивке вызывает `u8g2_DrawUTF8`, поэтому строки в
исходниках — UTF-8, а в шрифте обязательна Unicode-таблица (иначе коды
символов не совпадут с глифами). В наборе: ASCII 0x20–0x7E и кириллица А–я;
в мелком шрифте также Ё/ё.

Ограничение текущего набора: в основном шрифте нет `Ё/ё`, `№`, `—`, `…`, `«»`.
Поэтому пользовательские строки написаны без них («ждет», «Отчет»,
«Поврежденный», дефис вместо тире).

### Как перегенерировать

Данные взяты из исходников u8g2 (`font/u8g2_font_haxrcorp4089_t_cyrillic.c`,
`font/u8g2_font_5x7_t_cyrillic.c`) и проверены декодером глифов. Если в системе
есть `bdfconv` (u8g2 tools), предпочтительна генерация из BDF:

```bash
bdfconv -f 1 -m "32-126,1024-1103,1105,8470,8212,8230,171,187" \
        -n u8g2_font_haxrcorp4089_t_cyrillic \
        haxrcorp4089.bdf -o fn_font_primary.c
```

Результат — массив `const uint8_t[]` в формате u8g2; его вставляют в
`ui/fn_font.c`, затем проверяют:

1. `ufbt` собирается, размер `.fap` не вырос больше чем на бюджет;
2. на устройстве отображается контрольная строка
   «АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ» (US1, R6);
3. `python3 .test_scripts/units.py <имя>` — набор `fn_strings` (host) остаётся
   зелёным: все строки каталога непустые и без незапланированной латиницы.

## 3. Экраны

| View | Назначение |
|---|---|
| `FnMenuView` | главное меню, 5 пунктов, выбранный индекс сохраняется |
| `FnWaitView` | ожидание: анимация `A_FNLooking_64x64` + заголовок и подзаголовок |
| `FnTextView` | секции и строки из `FnTextModel`, прокрутка |
| `FnConfirmView` | подтверждение очистки МГМ |

Анимация: `icon_animation_alloc` + `view_tie_icon_animation` в `alloc`,
`icon_animation_start/stop` в enter/exit, `icon_animation_free` в `free`.
Ни одного `furi_delay_ms` в draw/input/сценах.
